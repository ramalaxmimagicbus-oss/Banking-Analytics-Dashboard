Banking Analytics Dashboard
 
## Project Overview
This project analyzes banking data to provide actionable business insights through interactive dashboards.
 
## Business Problem
Bank management needs a dashboard to monitor customer accounts, transactions, and business performance.
 
## Objectives
- Track KPIs
- Analyze customer trends
- Monitor performance
- Support business decisions
 
## Tools Used
- Power BI
- Excel
- Business Analysis
 
## Deliverables

- Business Requirements Document
- Insights Report
